Hermes Personal Assistant

Личный Telegram-ассистент для автоматизации повседневных задач владельца.

По команде владельца ассистент может обращаться к Google Sheets, Drive, Docs и Calendar, чтобы создавать и обновлять таблицы и документы, а также работать с календарём. Доступ предоставляется владельцем через Google OAuth и используется только для выполнения его запросов.

Приложение предназначено для личного использования. Регистрация других пользователей не предусмотрена.
