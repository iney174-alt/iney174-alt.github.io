Политика конфиденциальности

Hermes Personal Assistant · Последнее обновление: 10 октября 2026 г.

Hermes Personal Assistant — личный Telegram-ассистент, которым пользуется его владелец. Приложение не предлагает публичную регистрацию.

Какие данные обрабатываются

Когда владелец поручает задачу, ассистент обрабатывает текст команды и только те данные Google, которые необходимы для её выполнения. В зависимости от выданных разрешений это могут быть таблицы Google Sheets, файлы Google Drive, документы Google Docs и события Google Calendar.

Как используются данные

Данные используются для выполнения команды владельца: например, для поиска, создания или обновления таблиц и документов либо для работы с календарём. Данные Google не продаются и не используются для рекламы.

Хранение и защита

OAuth-токен, необходимый для доступа к Google, хранится на сервере владельца с ограниченными правами доступа. Содержание Google-файлов обрабатывается по мере выполнения поручений; приложение не публикует его на этом сайте.

Передача данных

Для выполнения поручения данные передаются соответствующему сервису Google через его API. Текст команды и нужный контекст также могут обрабатываться Telegram и подключёнными к личному ассистенту сервисами обработки запросов. Эти сервисы получают только данные, необходимые для ответа или выполнения команды, и обрабатывают их по собственным правилам конфиденциальности.

Срок хранения и отзыв доступа

Владелец может в любой момент отозвать доступ приложения в настройках безопасности Google-аккаунта. После отзыва ассистент перестанет обращаться к Google. Для запроса об удалении сохранённых данных или OAuth-токена напишите на iney174@gmail.com.
